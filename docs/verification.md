## 서비스 정책 및 미구현 범위

- 가입 식별자는 이메일이 아니라 `username`입니다. username은 영문·숫자·밑줄 3~30 ASCII자, 표시 이름은 40자·UTF-8 120바이트 이하, 비밀번호는 8자 이상·UTF-8 72바이트 이하입니다. 아이디와 같은 비밀번호 및 소규모 흔한 비밀번호 목록을 거절하고, 로그인에서도 72바이트 초과 입력을 거절해 bcrypt의 자동 잘림을 막습니다.
- 스터디 수정은 모집중 상태에서 스터디장만 가능하며, 정원을 현재 승인 인원 아래로 줄일 수 없습니다.
- 정원 충족은 승인 트랜잭션에서 `CLOSED/FULL`로 자동 마감합니다. 날짜 마감은 KST 날짜가 넘어간 뒤 목록·상세 조회와 지원·승인 요청에서 `CLOSED/DEADLINE`으로 지연 처리됩니다. 두 경우 모두 사유를 저장합니다. 멤버가 나가도 자동 재개하지 않습니다.
- 마감 상태에 남은 대기 지원은 승인할 수 없고, 스터디장이 시작할 때 한 번에 거절합니다. 이미 마감된 글을 다시 수동 마감하려는 요청은 409입니다.
- 작업 보드는 `ACTIVE` 상태에서만 변경할 수 있습니다. 모집 마감·종료·취소 상태는 읽기 전용입니다. UI 화면의 실제 동작과 모바일 배치는 캡처로 별도 확인해야 하며 자동 API 테스트가 이를 대신하지 않습니다.
- 거절된 지원서는 재지원할 수 없습니다. 지원자가 직접 취소한 PENDING만 모집 기간 중 같은 행으로 재지원할 수 있습니다.
- 작업 `todo`는 삭제되고 `doing`·`done`은 보관됩니다. 보관된 행은 작업 목록에 보관 표시로 남고, 보관 완료 작업은 진행률에 포함됩니다. 작업 상태 변경은 담당자나 스터디장, 삭제·보관은 해당 스터디 멤버나 스터디장이 할 수 있습니다.
- 배포 브라우저에서 390px 폭을 모의해 로그인·목록을 눈으로 확인했습니다. 비로그인 등록 폼은 숨겨지고 화면 가로 넘침과 Console 오류가 없었습니다. 실제 휴대폰 데이터망, 로그인한 역할별 전체 흐름, Network 탭 캡처, 화면 캡처와 시연 영상은 아직 제출 기록으로 남기지 않았습니다.
