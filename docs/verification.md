| 시연 데이터 초기화 | `npm run db:reset` 후 DB 조회 | A/B/C 계정, 정원 2명 중 한 명 승인된 모집글 | 통과: 테스트 DB에서 계정·정원 확인 |
| 브라우저 화면 | 가입부터 작업 완료까지 실제 조작 | 결과 표시, 새로고침 후 유지 | 아직 확인 전 |

사용자 터미널에서 Vitest 5.1.0으로 `npm install`, `npm test`, `npm audit`를 실행했습니다. **테스트 11/11 통과, 취약점 0건**입니다. 롤백 테스트는 멤버 추가 실패를 DB trigger로 주입하고 지원서 상태와 멤버 데이터가 모두 원복됨을 확인합니다. 실제 브라우저 검증과 화면 캡처는 아직 진행하지 않았습니다.
