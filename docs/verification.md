# 검증 기록

| 준비 상태 | 수행 동작 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 신규 사용자 | 회원가입 후 로그인 | 사용자 저장, JWT 발급 | 자동 테스트 작성, 실행 대기 |
| 정원 1, C와 D 지원 | A가 C 승인 후 D 승인 시도 | C 승인, D는 409, 멤버 1명 | 자동 테스트 작성, 실행 대기 |
| A 소유 스터디, B 계정 | B가 A의 지원 승인 시도 | 403, 데이터 불변 | 자동 테스트 작성, 실행 대기 |
| C의 대기 지원 | 중복 지원 또는 타인의 취소 | 409 또는 403 | 케이스 일부 작성, 실행 대기 |
| C가 승인 멤버 | 작업 `todo → done` 건너뛰기, 순방향 변경 | 건너뛰기는 거절, 순방향은 저장 | 자동 테스트 작성, 실행 대기 |
| 작업 0개 / 완료 작업 | 진행률 조회 | 0% / 100% | 0개 테스트 작성, 실행 대기 |
| 승인 중 멤버 INSERT 실패 주입 | 승인 요청 중 강제 오류 | 지원서 대기 유지, 멤버 없음 | 미구현: 트랜잭션 오류 주입 테스트 추가 필요 |
| 브라우저 화면 | 가입부터 작업 완료까지 실제 조작 | 결과가 표시되고 새로고침 후에도 유지 | 아직 확인 전 |

현재 실행 환경에서 `npm install`이 npm 레지스트리 `ENOTFOUND` 오류로 끝나 `npm test`는 `vitest: command not found`로 실행되지 않았습니다. 테스트 통과로 간주하지 않습니다. 자동 테스트 의존성을 설치한 뒤 이 표의 실제 결과를 기록하고, 화면 확인 캡처를 추가해야 합니다.
