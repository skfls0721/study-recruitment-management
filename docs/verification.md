## 의존성 감사

2026-11-19 `npm audit --omit=dev` 결과는 **취약점 0건**입니다. 전체 `npm audit`은 개발 도구 의존성인 `picomatch`를 통해 고위험 항목을 보고합니다. 같은 ReDoS 권고 및 의존성 경로에 걸리며, 현재 권고에는 패치 버전이 없습니다. 서비스 런타임 의존성에는 포함되지 않습니다. [GitHub Advisory GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)

## 서비스 정책 및 미구현 범위

- 가입 식별자는 이메일이 아니라 `username`입니다. username 형식(영문·숫자·밑줄 3~30자), 이름(40자 이하), 비밀번호(8~100자)를 검사합니다.
- 스터디 수정은 모집중 상태에서 스터디장만 가능하며, 정원을 현재 승인 인원 아래로 줄일 수 없습니다.
- 정원이 차도 스터디 상태를 자동으로 마감하지 않습니다. 모집글은 기존 상태를 유지하고 남은 대기 지원서는 PENDING으로 둡니다. 승인 시 정원을 다시 검사해 초과분에 409를 반환합니다.
- 거절된 지원서는 재지원할 수 없습니다. 지원자가 직접 취소한 PENDING만 모집 기간 중 같은 행으로 재지원할 수 있습니다.
- 작업 `todo`는 삭제되고 `doing`·`done`은 보관됩니다. 보관된 행은 작업 목록에 보관 표시로 남고, 보관 완료 작업은 진행률에 포함됩니다. 작업 상태 변경은 담당자나 스터디장, 삭제·보관은 해당 스터디 멤버나 스터디장이 할 수 있습니다.
- 실제 모바일 데이터망 접속, 전체 화면 흐름의 최신 브라우저 캡처, 콘솔·Network 탭 캡처, 시연 영상은 아직 제출 기록으로 저장하지 않았습니다. 사용자는 이전에 공개 화면과 로그인을 확인했습니다.
